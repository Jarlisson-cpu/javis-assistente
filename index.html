Instale no seu Windows

Requer Windows 10/11 e Python 3.13 ou mais novo.

Baixe o projeto

Pelo arquivo ZIP ou com o Git:

git clone https://github.com/Jarlisson-cpu/javis-assistente.git

Instale as dependências

Dentro da pasta do projeto:

pip install -r requirements.txt

Crie o seu usuário

O primeiro usuário vira administrador.

python main.py --criar-usuario seu_nome

Fale com ele

Diga “Jarvis” e o pedido. Também dá para usar --web (painel no navegador) ou --gui.

python main.py --voice
